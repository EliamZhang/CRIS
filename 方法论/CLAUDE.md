# CLAUDE.md — 消费金融风控方法论知识库索引

> 本文件是整个项目的知识路径总索引。查找任何风控知识时，先看这里定位，再打开对应的具体文件。

## 项目概述

本知识库覆盖消费金融信贷风控的完整方法论体系，从贷前审批到贷中运营到贷后催收，包含策略开发、策略调优、指标监控、模型应用、额度定价、反欺诈、合规监管等全链路内容。

**文件格式说明**：
- `.docx` 文件为方法论正文（文字 + 图表）
- `.xlsx` 文件为配套数据/测算案例
- `.md` 文件为策略专题深度文档

**版本说明**：
- V2 版本位于 `核心指标监控/` 目录
- V3 版本（基础版）位于 `信贷全流程方法论/` 目录
- V3 增强版位于 `信贷全流程方法论 - 增强版/` 目录（内容更详细）

| 场景 | 推荐版本 |
|------|----------|
| 快速了解框架和基本概念 | 基础版（信贷全流程方法论/） |
