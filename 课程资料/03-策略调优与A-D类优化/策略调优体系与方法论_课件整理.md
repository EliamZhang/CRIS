# 第一部分：策略调优体系和方法论

## 1. 什么是策略调优

风控策略上线后并非一成不变，会持续受到以下因素影响：

- 业务发展阶段和业务目标发生变化；
- 客群质量变好或变差；
- 监管政策变化，例如定价上限调整；
- 数据下线、数据质量变化或变量效果衰减；
- 市场、产品、技术和决策流程发生变化。

**策略调优**就是根据当前最新变化，对已有策略进行调整，使其重新适应业务和风险环境。

核心观点：

> 没有永远最优的策略，只有在当前环境下最合适的策略。

## 2. 策略调优的价值

### 2.1 根据市场周期调整风险偏好

- 市场环境较好时，可适度激进，以扩大规模、快速获取客户和形成规模效应为主要目标；
- 市场环境较差时，应偏保守，以稳定经营、控制新客风险和消化存量资产为主。

### 2.2 调整时点非常关键

风险具有滞后性：

- 若能在市场变差前提前识别趋势并收紧，后续贷后压力较小；
- 若等风险集中暴露后再调整，逾期和资产处置压力会明显增加。

## 3. 策略调优的两个方向

策略调优主要围绕两个指标：

- **通过率**
- **逾期率 / 坏账率**

### 3.1 A 类调优：提高通过率

A 为 **Ascending** 的缩写。

目标：从原策略拒绝的客户中识别相对优质客户并放行，在风险可控前提下提升通过率。

### 3.2 D 类调优：降低通过率

D 为 **Descending** 的缩写。

目标：从原策略通过的客户中识别高风险客户并拒绝，通过收紧降低逾期率。

| 维度 | A 类调优 | D 类调优 |
|---|---|---|
| 核心目标 | 提高通过率 | 降低逾期率 |
| 操作对象 | 原来被拒绝的客户 | 原来被通过的客户 |
| 数据难点 | 拒绝客户通常没有贷后表现 | 通过客户通常已有贷后表现 |
| 分析难度 | 较高，需要预测或测试 | 相对较低，可直接量化 |

## 4. 策略调优的通用步骤

1. 分析需求，确定调整的是规则、规则集还是模型；
2. 判断属于 A 类调优还是 D 类调优；
3. 量化分析，根据分析结果制定方案；
4. 执行方案，测算调整后的效果；
5. 通过评估指标验证是否符合预期；
6. 循环执行步骤 3–5，直到找到较优方案。

## 5. A 类调优的业务场景

### 5.1 资金充足且有业绩压力

当资金充足、现有通过率下的客户无法消耗全部资金时，可适度提高通过率，以完成贷款规模或业绩目标。常见于有明确放款规模要求的银行和金融机构。

### 5.2 策略过于保守

在风险可控且仍有较大利润空间时，可放松策略、扩大客户范围。典型场景是业务冷启动阶段：早期由于风险未知，通过率偏低；随着贷后表现积累，若发现风险明显低于预期，说明原策略偏保守。

### 5.3 监控报表显示通过率下降

若规则或模型命中率持续升高，导致整体通过率异常下降，需要定位原因并调优，使通过率恢复到正常水平。

## 6. A 类调优的方法

### 6.1 宏观调优：客群下探

调整幅度较大，主要包括：

- 下探新的风险客群；
- 为下探客群设计差异化审批策略；
- 配套调整额度、定价、期限和产品规则。

### 6.2 微观调优

调整幅度相对较小，包括：

- **拒绝回捞**：从策略中间节点被拒绝的客户中，有条件地捞回；
- **策略放松**：放松规则或模型 cutoff；
- **策略下线**：下线无效或衰减策略；
- **策略替换**：使用新策略替换旧策略，分析置入和置出客群。

A 类调优的核心难点是拒绝客户没有真实贷后表现，通常需要预测、历史测试或 AB 测试辅助判断。

## 7. D 类调优的业务场景

### 7.1 监控发现逾期率上升

通过风险监控报表发现逾期指标持续上升，需要及时定位原因并收紧策略。

### 7.2 实际逾期率超过预期目标

实际风险表现明显高于预算或风险目标，需要调整策略，使风险重新回到目标范围。

### 7.3 放款头寸减少

当机构可用资金不足时，可通过收紧策略，只向相对优质客户放款。

### 7.4 市场环境下行，需要控制风险敞口

当外部市场恶化、资产质量整体变差时，可通过收紧客群和审批规则降低风险敞口。

## 8. D 类调优的方法

### 8.1 宏观调优

对整体风险客群进行收紧，例如：

- 收紧主模型高风险等级；
- 降低高风险客户授信额度；
- 对风险较高客群进行无差别收紧。

### 8.2 微观调优

针对某个具体维度收紧，包括：

- **策略收紧**：调整规则或模型阈值；
- **策略替换**：通过 swap-in/swap-out 分析替换旧策略；
- **策略新增**：增加新的规则或数据维度。

# 第二部分：基于单变量规则的 A 类调优

## 1. 什么是规则阈值放松

示例规则：

- 变量：最近一个月贷款审批查询次数；
- 当前规则：`RULE0 >= 5` 时拒绝；
- 放松后：调整为 `RULE0 >= 6` 时拒绝。

调整后，原来取值为 5、会被拒绝的客户可以被放行，从而提高通过率。

## 2. 阈值放松的核心难点

被拒绝客户无法借款，因此没有真实贷后表现，其风险是未知的。

因此，以下两个问题难以直接量化：

- 该规则是否可以放松；
- 放松到什么程度最合理。

## 3. 拒绝样本贷后表现的三类量化方法

### 3.1 回归预测

适用条件：

- 规则通过样本分箱后的坏账率具有较明显单调性；
- 规则本身有一定风险区分能力。

方法：

1. 使用通过样本各分箱的 bad rate 拟合回归关系；
2. 根据趋势预测拒绝段分箱的 bad rate；
3. 判断释放拒绝段后的风险水平。

课件示例中，拒绝段第 5、6 分箱预测 bad rate 分别约为：

- 16.42%
- 19.14%

### 3.2 借助其他强变量预测

当规则本身的 bad rate 单调性不明显时，可借助其他强变量，例如：

- 主模型分；
- 融合模型分；
- 其他稳定、区分能力较强的风险变量。

示例：使用“模型分 0”预测规则 1 在 `[5,6)` 拒绝段的风险。根据模型分分箱下的样本数及 bad rate 加权，得到拒绝段预测坏账率：

```text
173 / 2000 = 8.65%
```

### 3.3 实际测试

若历史做过灰度或 AB 测试，可直接参考历史测试数据；若没有，可通过随机测试获取真实贷后表现。

## 4. 回归预测实操

### 4.1 Python 方法

课件通过 `numpy.polyfit()` 拟合一元线性回归，示例方程为：

```text
y = 0.0271x + 0.0286
```

然后使用该方程预测拒绝样本对应分箱的 bad rate。

### 4.2 Excel 方法

1. 选中分箱及 bad rate 数据，插入折线图；
2. 右键折线图，选择“添加趋势线”；
3. 选择线性趋势线；
4. 勾选“显示公式”和“显示 R² 值”；
5. 根据拟合方程外推拒绝段 bad rate。

## 5. 随机测试、AB 测试和灰度测试

### 5.1 随机测试

- 分流比例不宜过高，一般控制在 2% 以内；
- 样本量仍需满足最小统计要求；
- 测试样本只打分、不生效，并直接绕过后续拒绝策略；
- 若仍可能被后续策略拒绝，获取的贷后表现会失真；
- 需要等待完整观察期，优点是信息准确、无需模型预测。

### 5.2 AB 测试

- A 组：规则只打分、不生效；
- B 组：规则正式生效；
- A 组中低于新 cutoff 且实际放款的客户，其 bad rate 可近似作为 B 组拒绝客群的风险估计。

### 5.3 灰度测试

若策略正式上线前存在一段“只打分、不生效”的灰度期，可使用灰度期样本估算拒绝客群 bad rate。

# 第三部分：规则集 A 类调优

## 1. 规则集调优的特点

并行规则集可以无差别获取内部每条规则的命中状态，因此特别适合进行规则层面的归因和调优。

规则集 A 类调优的一般流程：

1. 单一命中率分析；
2. 贷后逾期分析和 cutoff 放松；
3. 重新计算规则集整体性能；
4. 若效果不理想，返回前两步继续调整。

## 2. 单一命中率相关指标

### 2.1 自然命中率

```text
自然命中率 = 规则 A 命中客户数 / 总客户数
```

其中包含规则 A 与其他规则交叉命中的客户。

### 2.2 单一命中率

```text
单一命中率 = 只有规则 A 命中、其他并行规则均未命中的客户数 / 总客户数
```

该指标更能反映放松某条规则后，对规则集整体通过率的直接影响。

### 2.3 单一命中纯度

```text
单一命中纯度 = 单一命中率 / 自然命中率
```

它反映规则命中客户中，独立命中的占比。其余部分属于与其他规则重复命中。

## 3. 规则筛选原则

1. 优先寻找连续型弱规则；
2. 排除强规则、政策性规则和可调空间较小的非连续性规则；
3. 优先选择单一命中率较高的规则；
4. 同时关注单一命中纯度，判断调整是否能真正影响综合命中率。

## 4. 单一命中率案例

课件示例中，仅调整 `RULE7`：

- RULE7 单一命中率由约 3.8% 降至 2.1%；
- 降低约 1.7 个百分点；
- 整个规则集综合命中率由 17.5% 降至 15.8%；
- 同样降低约 1.7 个百分点。

说明当一条规则的单一命中占比较高时，其调整幅度会直接反映到规则集整体命中率上。

## 5. 贷后逾期分析

A 类调优需要判断被释放拒绝段的风险。核心原则是：

> 优先释放预计逾期率更低的拒绝段。

### 5.1 有拒绝数据

若历史随机测试、AB 测试或灰度测试已经积累拒绝段贷后表现，可直接比较各规则拒绝段的历史逾期率，优先释放风险较低的规则或区间。

### 5.2 无拒绝数据

若没有真实贷后数据，可使用：

- 分箱 bad rate 单调性进行外推；
- 强模型分预测；
- 历史相似产品或相似规则表现；
- 小比例随机测试。

课件示例中，三个候选释放点预测 bad rate：

| 规则释放点 | 预计 bad rate |
|---|---:|
| RULE0 = 5 | 约 16% |
| RULE4 = 4 | 约 19% |
| RULE7 = 2 | 约 12% |

应优先考虑风险较低的 RULE7 拒绝段。

## 6. 重新计算规则集性能

规则之间存在重复命中，不能简单把单条规则的变化直接相加。完成阈值调整后，需要重新运行整个规则集，计算：

- 综合命中率；
- 通过率变化；
- 单一命中率变化；
- 各规则重叠和替代关系；
- 预计逾期率变化。

若效果未达到预期，可继续：

- 进一步放松阈值；
- 同时放松多条规则；
- 对多个候选组合并行测算并选择较优方案。

# 第四部分：基于拒绝回捞的 A 类调优

## 1. 什么是拒绝回捞

拒绝回捞是指让原本被策略拒绝的部分客户重新通过。

- 广义上：等同于各类 A 类调优；
- 狭义上：指决策流程中专门设置的回捞节点或回捞动作。

主要目的：减少对好客户的误杀，同时在可控范围内提高通过率。

## 2. 拒绝回捞的核心逻辑

1. 寻找明显的好客户特征；
2. 这些特征最好与前面导致客户被拒绝的风险维度相关性较低；
3. 使用强特征或多维特征组合，覆盖或抵消客户原有风险；
4. 从拒绝客户中筛选相对优质客户重新通过。

典型的强好客户特征包括：

- 公务员、事业单位员工；
- 500 强企业员工；
- 高公积金缴存基数；
- 内部优质客户白名单；
- 高质量企业单位员工；
- 明显较低的资金紧张程度；
- 较高的主模型或融合模型分。

## 3. 回捞规则设计

### 3.1 强单一规则回捞

适合希望明显提升通过率的场景，例如：

```text
若命中机构内部白名单，则直接回捞通过。
```

优点：回捞力度大；缺点：覆盖较粗。

### 3.2 多维度交叉回捞

适合希望提高回捞精准度的场景，例如：

```text
内部白名单 = 是
且 三方融合模型分 > 700
则回捞通过
```

优点：风险更可控；缺点：命中率和通过率提升相对较低。

### 3.3 回捞规则集示例

**无差别回捞：**

- 优质客户白名单；
- 优质企业单位员工 + 公积金推测收入 > 8000。

**有针对性回捞：**

- 近 2 年有负债但无逾期 + 违约成本高；
- 资金紧张评级低 + 模型分 A > 600；
- 征信白户 + 模型分 B > 700。

一套回捞策略可由多条规则组成，并可配置为串行或并行规则集。

## 4. 征信白户回捞示例

某公司此前对征信白户直接拒绝，计划下探该客群。由于征信信息不足，可使用第三方融合模型补充判断。

课件示例：

- 整体样本 bad rate：4.48%；
- 融合模型分 `>= 800` 的 bad rate 低于 2%；
- 回捞规则可设计为：

```text
征信白户
且 三方融合模型分 >= 800
则回捞通过
```

## 5. 拒绝回捞流程设计

### 5.1 确定不可回捞对象

政策准入、黑名单等原则性底线通常不可回捞。

### 5.2 确定回捞对象

可根据业务需求选择：

- 仅回捞信用规则拒绝客户；
- 仅回捞欺诈规则拒绝客户；
- 对多个节点的拒绝客户回捞。

不同对象对应不同的回捞节点位置。

## 6. 拒绝回捞离线分析

1. **确定回捞变量**：通过数据分析和业务经验寻找明显好客户特征；
2. **回溯变量**：与历史通过、拒绝样本及决策结果对齐；
3. **筛选变量**：统计候选客群被原策略拒绝的比例，判断回捞空间；
4. **设计并执行回捞策略**：计算命中率、通过率和风险；
5. **评估和调整**：根据结果反复优化，并使用近期样本验证稳定性。

### 6.1 通过率评估

主要关注：

- 整体回捞策略命中率；
- 每条回捞规则的单一命中率；
- 回捞客户在不同决策节点的分布。

### 6.2 风险评估

- 若使用已有贷后表现的变量，可直接计算 bad rate；
- 若使用新变量，需要随机测试、AB 测试、灰度测试或模型预测；
- 回捞客群应相较整体风险有明显优势。

课件示例：若整体 bad rate 为 2%，回捞客群 bad rate 最好控制在 1.5% 以下，否则回捞意义有限。

## 7. 上线与监控

### 7.1 AB 测试上线

示例分流：

- 20%：执行回捞，作为实验组；
- 80%：保持原策略，作为对照组；
- 为回捞客户打标签，便于后续分析。

### 7.2 上线初期

资产尚无完整贷后表现，重点监控：

- 回捞客群占比是否稳定；
- 是否与离线分析一致；
- 是否出现单日回捞量突然上升。

回捞量异常上升通常是风险预警信号。

### 7.3 上线中期

当有 FPD7、FPD15、FPD30+ 等指标后，比较回捞客群与大盘风险：

- 若回捞风险接近或高于大盘，应下线或调整；
- 若回捞风险明显较低，可逐步扩大实验比例。

### 7.4 上线后期

使用 DPD30+、term3/4/5 等更成熟指标评估风险，稳定后可全量上线；同时持续监控：

- 回捞命中率；
- 单一命中率；
- 失效规则；
- 客群和变量漂移。

# 第五部分：客群对象上的 A 类调优——客群下探

## 1. 客群下探的理解和应用场景

客群下探是对被策略拒绝的一类风险客群进行适度放开。

与具体规则微调相比：

- 规则调整更像“战术调整”；
- 客群下探更像“战略调整”。

客群下探通常相当于开发一个新的风险产品，需要业务、产品、风控和研发共同配合，重新设计：

- 产品要素；
- 审批流程；
- 风控策略；
- 额度、定价和期限；
- 贷后监控和风险处置。

典型应用场景：

- 业务冷启动时通过率较低；
- 已积累一定贷后表现；
- 当前通过客群风险稳定；
- 安全垫较高，说明策略偏保守；
- 企业希望扩大业务量和收益。

## 2. 客群下探的意义

### 2.1 市场端

尽量留住自身流量和客户资源，减少因过度拒绝产生的资源浪费。

### 2.2 资产端

丰富资产结构，支持多业务条线并行发展。

### 2.3 风控端

可显著提高授信审批通过率，但大盘风险通常也会提升，因此需要：

- 更严格的审批规则；
- 更谨慎的产品参数；
- 更完善的风险监控。

是否下探需结合公司整体风险偏好。若以收益最大化为目标，只要仍有盈利空间并符合监管要求，可继续下探，直到边际收益下降，再考虑收紧。

## 3. 客群下探策略

### 3.1 下探模型分层的风险等级

当前多数贷前策略以模型分为主、规则为辅，可通过放宽模型分层的准入等级实现客群下探。

例如：

- 原来只通过 A、B 客群；
- 下探后将 C 客群部分或全部纳入通过范围。

### 3.2 阶梯式下探

由于新客群风险未知，可对新增风险等级单独设置审批规则：

1. 先让部分 C 客群有条件通过；
2. 为 C 客群增加额外审批规则；
3. 累积一定贷后表现；
4. 根据表现决定继续下探或收紧。

这种方式类似白名单冷启动，避免一步到位，便于控制风险。

## 4. 客群下探效果测算

### 4.1 风控指标：通过率和逾期率

#### 通过率测算

提取近期决策数据，统计不同模型风险等级的客户占比。

课件示例：C 等级客户月均占比为 18.2%。

- 若 C 等级全部放行，理论上整体通过率可提升约 18.2 个百分点；
- 若对 C 等级增加审批规则，则实际提升低于 18.2%。

示例月均申请量：

| 风险等级 | 月均申请量 | 月均占比 |
|---|---:|---:|
| A | 1247 | 19.3% |
| B | 1454 | 22.4% |
| C | 1167 | 18.2% |
| D | 1526 | 23.9% |
| E | 652 | 10.3% |
| F | 140 | 约 2.2% |
| 总计 | 6186 | 100% |

#### 逾期率测算

风险预测难度较高，可参考：

- 历史随机测试；
- AB 测试；
- 公司已有类似产品；
- 市场同类产品风险表现；
- 通过客户不同风险等级的区间坏账率，并进行线性外推。

### 4.2 业务指标：业务规模和收益

示例公式：

```text
每月新增放款规模
= C 等级月均申请客户数
× 用信转化率
× 件均额度
× 额度系数
```

在不考虑提前结清等复杂因素时，可按月累计估算中长期新增在贷余额和收入。

## 5. 风险预警和处置

客群下探前需要设计两条风险线：

### 5.1 拉闸线

风险底线，不允许突破。一旦超过，应直接暂停或整顿业务。

### 5.2 预警线

在接近拉闸线前触发预警，便于提前排查和调整，避免业务被迫停摆。

预警线应结合产品风险暴露节奏设置。

课件示例：

- 拉闸线设为 3%；
- 对先息后本产品，风险集中在后期，可将预警线设得更低，例如 2%；
- 对等额本息产品，风险释放更均匀，可适当设为 2.5%。

## 6. 客群下探的产品设计

基于模型分层的下探，本质上是进入一个新的风险区间，应视为新产品进行设计。

一般原则：风险越高，通常需要：

- 额度更低；
- 定价更高；
- 还款期限更短；
- 资金占用更低；
- 还款方式更稳健。

### 6.1 产品调整示例

原 A/B 风险客群产品：

- 定价：3%–8%；
- 额度上限：20 万；
- 还款方式：先息后本或等额本息；
- 先息后本最长 1 年；
- 等额本息最长 3 年。

下探 C 风险客群后：

- 定价：8%–12%；
- 额度上限：10 万；
- 还款方式：仅等额本息；
- 最长期限：1 年。

示例风险定价区间：

| 模型等级 | 定价 |
|---|---:|
| A | 3%–5% |
| B | 5%–8% |
| C | 8%–12% |
| D | 12%–18% |
| E | 18%–24% |
| F | 24%–36% |

## 7. 产品优化和用信转化

产品参数过于保守可能出现：

- 授信通过率提升；
- 但额度太低或定价太高；
- 客户不愿用信；
- 最终业务规模仍无法打开。

可通过 AB 测试优化额度和定价：

- 调整定价后转化无变化，说明客群对定价不敏感，可能更关注额度；
- 调整额度后转化无变化，说明客群可能更关注利率；
- 优质客群通常对定价更敏感；
- 下沉客群往往对额度更敏感，因为不同机构的定价普遍较高，客户更关心能获得多少额度。

# 第六部分：规则的 D 类调优——cutoff 收紧

## 1. 什么是策略收紧

狭义策略收紧是指调整规则或模型 cutoff，将原本通过的部分客户改为拒绝，以降低逾期率。

该方法仅调整已有规则或模型本身，不依赖：

- 新增变量；
- 新增策略；
- 策略替换。

规则收紧通常影响某个具体风险维度；模型阈值收紧通常影响更广的整体风险客群，因此对通过率和逾期率的影响更大。

D 类调优基于已有通过客户贷后表现，数据基础比 A 类调优更完整，量化分析相对容易。

## 2. 阈值收紧分析步骤

1. 明确调优需求：政策变化、市场变化、资产质量下降、逾期率上升等；
2. 提取合适的历史样本，保证代表性、充分性、时效性和数据可回溯；
3. 从大到小寻找高风险规则或风险区间；
4. 对规则进行分箱，计算 bad rate、Lift 等指标；
5. 制定一个或多个收紧方案；
6. 在历史样本和近期样本上测试通过率、逾期率变化；
7. 若不符合要求，重新调整，直到得到最终方案。

## 3. 量化分析示例

背景：近期 FPD7+ 持续上升并触发预警，分析发现某规则集通过样本风险较高。

分析方法：

1. 对规则集内部每条规则分箱；
2. 计算区间 bad rate 和 Lift；
3. 寻找高 Lift 且具有业务解释的风险区间；
4. 确定需要收紧的规则。

示例变量：近 6 个月申请贷款机构数。

- 原规则：`>= 4` 时拒绝；
- `[3,4)` 区间 bad rate 接近 31%；
- 该区间 Lift 约 3.87；
- 大盘平均风险约 7.95%；
- 因此可将规则调整为 `>= 3` 时拒绝。

## 4. 收紧规则的筛选经验

1. 优先选择 bad rate 单调性较好的变量；
2. 变量应有合理业务含义；
3. 优先选择 Lift 较高的区间；
4. 信贷场景中 Lift 约 2–3 以上通常可视为有较明显增益；
5. 对所有候选变量按 Lift 排序；
6. 同时分析规则单一命中率和与其他规则的重叠关系。

## 5. 规则集代码测算的核心指标

课件中的 Python 函数用于执行调整后的规则集，并计算：

- 每条规则自然命中率；
- 单一命中率；
- 单一命中纯度；
- 规则集综合命中率；
- 规则之间的重复和替代关系。

## 6. 效果评估

D 类 cutoff 收紧后，理论上：

- 通过率下降；
- 逾期率下降。

由于两个指标量纲不同，应比较相对下降幅度。

课件示例：

- 逾期率下降 20%；
- 通过率下降 6.79%；
- 表明拒绝了较少的好客户，同时拒绝了更多坏客户，策略具有较好效果。

### 6.1 日常微调

业务通常不允许通过率大幅下降，可控制在约 1%–2% 或基本不变。

### 6.2 大规模收紧

应进一步进行成本收益测算，综合考虑：

```text
资金成本 + 人力成本 + 投放成本 + 运营成本 + 数据成本 + 风险损失
与
利息收入 + 罚息收入
```

若某类客群的综合成本明显高于收益，则拒绝该客群具有经济合理性。

# 第七部分：策略新增的 D 类调优

## 1. 什么是策略新增

策略新增是在保持已有策略不变的基础上，增加新的审批策略，以实现 D 类收紧。

常见场景：

- 已有策略没有进一步收紧空间；
- 通过调整已有 cutoff 无法达到业务目标；
- 需要接入其他维度的数据；
- 新增三方数据源、模型分或衍生变量进行补充。

由于旧策略不变、额外增加拒绝条件，整体通过率会下降。

## 2. 策略新增分析流程

1. 明确调优需求；
2. 提取历史样本并回溯数据；
3. 开发新策略；
4. 将新策略融入旧策略并生成决策结果；
5. 在历史和近期样本上测算通过率及逾期率；
6. 通过灰度测试或 AB 测试后正式上线。

## 3. 新增策略的常见形态

### 3.1 单变量规则

使用一个变量和一个 cutoff，逻辑简单、命中率通常较高，但可能误伤较多。

### 3.2 二维交叉规则

使用两个变量交叉形成风险矩阵，可在保持风险识别能力的同时降低误伤。

### 3.3 多维规则

可由决策树生成多维变量组合。

总体规律：

> 维度越多，复杂度越高，命中率通常越低，但识别更精准。

需要同时兼顾：

- 逾期率；
- 通过率；
- 命中率；
- 业务可解释性；
- 工程复杂度。

## 4. 策略变量的来源

### 4.1 同一维度的新变量

例如征信变量团队开发新的征信衍生变量，与线上规则具有一定区分，验证稳定后可加入现有征信规则集。

### 4.2 不同维度的新数据

例如接入新的数据源、三方模型分或行为变量。若其风险区分能力较好，且与原策略相关性较低，可作为增量补充。

## 5. 制定策略和效果测算

### 5.1 必须使用同一批样本

旧策略和新策略需要在同一批样本上计算，才能进行公平的增量效果比较。

### 5.2 区分能力好不等于有增量

新变量可能与旧策略高度相关或大量重复命中，即使单变量效果很好，也不一定对整体策略产生提升。

需分析：

- 变量相关性；
- 命中重叠；
- 二维交叉矩阵；
- 是否具有“互有单调性”；
- 新增后的单一命中和增量命中。

### 5.3 单变量和二维规则对比示例

课件示例：

- 单变量规则新增命中约 12.8%，相当于通过率下降约 12.8%；
- 被拒绝样本坏客户浓度较高，但通过率下降幅度可能过大；
- 二维交叉规则通过率仅下降约 6.85%，调整更平滑；
- 但二维交叉规则的逾期率下降幅度可能不如单变量规则明显。

因此，需要在风险改善和业务规模之间进行权衡。

# 第八部分：置换策略的 D 类调优

## 1. 什么是置换策略

置换策略又称 **swap-in / swap-out**，是使用一套全新的策略替换旧策略。

与 cutoff 收紧和策略新增不同：

- 不是在旧策略上微调；
- 不是叠加新的拒绝条件；
- 而是完整替换原策略。

置换对象可以是：

- 规则策略；
- 规则集；
- 模型策略；
- 主模型或融合模型。

典型场景：线上主模型 KS 等指标持续下降，模型团队交付新模型后，策略团队需从业务角度比较新旧模型的通过率和风险表现。

## 2. 什么是置入和置出

- **置入（swap-in）**：旧策略拒绝、新策略通过；
- **置出（swap-out）**：旧策略通过、新策略拒绝。

置换分析重点关注新旧策略决策不一致的客户。

理想状态：

- 置入客群坏账率较低；
- 置出客群坏账率较高；
- 说明新策略用更低风险客户替换了更高风险客户。

## 3. 分析流程

1. 明确调优需求；
2. 提取代表性、充分且可回溯的样本；
3. 开发新模型或新策略；
4. 分别运行新旧模型，生成通过/拒绝结果；
5. 构建决策交叉矩阵；
6. 进行效果测试；
7. 灰度或 AB 测试后上线。

效果判断原则：

- D 类调优：尽量保持通过率相同，比较坏账率；
- A 类调优：尽量保持坏账率相同，比较通过率。

## 4. 决策结果交叉分析

课件示例共有 50,000 个客户：

| 旧模型 \ 新模型 | 通过 | 拒绝 | 合计 |
|---|---:|---:|---:|
| 通过 | 36,417 | 3,990 | 40,407 |
| 拒绝 | 6,729 | 2,864 | 9,593 |
| 合计 | 43,146 | 6,854 | 50,000 |

对应客户占比：

| 旧模型 \ 新模型 | 通过 | 拒绝 | 合计 |
|---|---:|---:|---:|
| 通过 | 72.83% | 7.98% | 80.81% |
| 拒绝 | 13.46% | 5.73% | 19.19% |
| 合计 | 86.29% | 13.71% | 100% |

旧模型通过样本中：

- 新旧均通过：36,417 人，坏客户 1,641，bad rate 4.51%；
- 旧模型通过、新模型拒绝：3,990 人，坏客户 1,508，bad rate 37.79%；
- 旧模型整体通过样本 bad rate：7.79%。

由此可见，置出部分风险较高。

## 5. 新旧效果对比原则

先调整新模型 cutoff，使新旧模型通过率尽量可比；然后比较：

- 置入部分 bad rate；
- 置出部分 bad rate；
- 新旧模型整体通过客群 bad rate；
- 新旧模型通过率。

如果置入 bad rate 低于置出 bad rate，说明新模型替换方向合理。

## 6. 置入样本坏账率预测——离线估计

旧模型拒绝样本通常没有贷后表现，因此置入部分风险需要预测。

课件方法：

1. 使用新模型对原通过样本进行风险分层，计算各层 bad rate；
2. 将相同风险分层应用到旧模型拒绝样本；
3. 统计旧拒绝样本在各风险层的数量；
4. 使用“各层样本数 × 新模型通过样本对应层 bad rate”，估算坏客户数；
5. 根据新模型 cutoff 汇总置入部分预计 bad rate。

示例结果：

- 置入客户数：6,729；
- 预计坏客户数：448；
- 预计置入 bad rate：6.65%。

完成估计后的对比：

| 指标 | 结果 |
|---|---:|
| 新模型通过率 | 86.29% |
| 旧模型通过率 | 80.81% |
| 置入部分预计 bad rate | 6.65% |
| 置出部分 bad rate | 37.79% |
| 新模型整体通过部分预计 bad rate | 4.84% |
| 旧模型整体通过部分 bad rate | 7.79% |

该结果表明新模型理论上可在提高通过率的同时降低通过客群风险。

### 6.1 离线估计的局限

新模型通常在通过样本上开发，再用于预测旧模型拒绝样本，存在客群偏差，因此置入 bad rate 可能被低估。

## 7. 线上测试方法

### 7.1 AB 测试

- A 组：旧模型只打分、不生效；
- B 组：旧模型正式生效；
- A 组中被旧模型判为拒绝、但实际放款的客户，可用于估计旧模型拒绝段风险。

### 7.2 灰度测试

若旧模型上线前有一段只打分、不生效的灰度期，可使用灰度期数据估计拒绝样本 bad rate。

### 7.3 随机测试

- 比例通常控制在 2% 以内；
- 样本需达到最小统计要求；
- 测试客户应直接通过，不再被后续策略拒绝；
- 等待完整观察期后获取真实风险表现。

# 九、整套方法论的核心总结

## 1. 先确定目标，再选择方法

- 需要扩大业务、提高通过率：A 类调优；
- 需要控制风险、降低逾期：D 类调优。

## 2. A 类调优的最大问题是风险未知

拒绝样本没有贷后表现，因此需要通过：

- 回归外推；
- 强变量预测；
- 相似客群参照；
- 随机、AB 或灰度测试。

## 3. D 类调优的重点是增益效率

不能只看逾期率是否下降，还要判断：

- 为降低风险牺牲了多少通过率；
- 被拒绝客户中的坏客户浓度；
- 是否存在高 Lift、高单一命中的可调规则；
- 调整后的成本收益是否合理。

## 4. 规则、规则集、模型和客群需要分层分析

| 层级 | 典型方法 |
|---|---|
| 单条规则 | cutoff 放松或收紧 |
| 规则集 | 单一命中、纯度、重叠关系、整体重算 |
| 决策流程 | 拒绝回捞、节点调整 |
| 模型 | 风险等级调整、模型置换 |
| 客群 | 客群下探、差异化产品设计 |

## 5. 离线分析后必须进行线上验证

完整闭环应包括：

1. 离线量化；
2. 历史样本和近期样本验证；
3. 灰度或 AB 测试；
4. 小流量上线；
5. 监控命中率、通过率、FPD、DPD 和客群漂移；
6. 根据真实贷后表现继续迭代。
