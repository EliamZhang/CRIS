# 06-信贷投放专题 · 目录说明

投放渠道策略（Google / Facebook / TikTok / 应用商店）、流量获取与风控结合、投放博弈论、投放数据分析方法论。

## 文件命名规范

统一格式：**`序号_角色_主题.扩展名`**，序号为两位数字，角色用于区分文件用途：

| 角色 | 命名格式 | 用途 | 现有文件 |
|------|----------|------|----------|
| 延伸阅读 | `NN_延伸阅读_<主题>.md` | 系列文章整理合集，配套专题综述做主题深化 | 01 |
| 实操教程 | `NN_实操教程_<平台>_<主题>.md` | 具体媒体平台（Google 等）的落地操作教程 | 02 |
| 工具 | `NN_工具_<名称>.html` | 可独立打开的可视化工具 / 看板 | 04 |

两个固定文件不加序号，遵循仓库约定：

- `信贷投放专题_专题综述.md` — 主教材（与专题研修其他篇目的 `<主题>_专题综述.md` 一致）
- `学习笔记_信贷投放专题.md` — 对话学习课程档案（遵循《学习笔记_<专题>.md》约定）

**新增文件时**：先判断角色（延伸阅读 / 实操教程 / 工具 / 其他），序号全角色统一递增、取现有最大序号 +1；新角色先在此表登记再使用。
