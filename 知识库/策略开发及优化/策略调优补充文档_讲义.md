# 风控策略调优体系与方法论

> **课程定位**：策略分析师进阶核心技能 | **适用阶段**：业务发展中期的必做工作 | **核心目标**：掌握A类/D类调优的完整方法论与实操流程

---

## 一、策略调优概述

### 1.1 什么是策略调优

风控策略开发上线后**并非一成不变**。策略会受到业务目标、市场变化、数据质量、监管政策等多方面因素影响，需要不断优化调整以适应最新变化。

**策略调优的本质**：根据当前最新的变化（来自业务、市场、产品、数据、技术等多维度），对现有策略做出调整，以找到不同环境下最合适的策略。

> **核心原则**：没有最完美的策略，只有在不同变化、不同环境下最合适的策略。

### 1.2 为什么需要策略调优

| 影响因素 | 具体场景 | 调优响应 |
|---------|---------|---------|
| 业务目标变化 | 不同阶段有不同的业务目标（规模扩张 vs 风险收敛） | 策略跟随调优 |
| 客群质量变化 | 客群变好或变差 | 策略放松或收紧 |
| 监管政策变化 | 如定价不得高于24% | 策略合规调整 |
| 数据源变化 | 数据源下线或效果衰减 | 策略下线或替换 |
| 市场环境变化 | 经济上行/下行周期 | 风险偏好调整 |

### 1.3 策略调优的核心难点

1. **发现优化点**：需要策略分析师具备极强的业务敏感性，及时捕捉优化机会（依赖经验积累）
2. **寻找更优方案**：需挑战现有策略，找到当前环境变化中最好的方案
3. **验证优化效果**：通过反复对比各种方案，找到最优解，并通过测试、测算等方法证实

> **经验型观点**：风险往往是滞后的。在市场环境变坏之前提前捕捉并收紧策略，后期贷后压力会小很多；若等到环境变差再调整，可能已来不及。

### 1.4 风控策略主基调

根据公司风控部门整体风险偏好制定，通常分为三类：

| 风险偏好 | 适用市场环境 | 核心策略 | 客群特征 |
|---------|------------|---------|---------|
| **激进型** | 市场行情好 | 迅速占有市场，快速扩大规模，形成规模效应 | 新客户为主 |
| **保守型** | 市场行情不好 | 平稳发展，吸收存量客户，谨慎处理高风险新客户 | 存量客户为主 |
| **平稳型** | 市场稳定 | 平衡规模与风险 | 新老客户均衡 |

## 二、策略调优的两大方向

策略调优围绕**两个核心指标**展开：**通过率** 与 **逾期率**。

### 2.1 方向对比总览

```
┌─────────────────────────────────────────────────────────────┐
│                    策略调优两大方向                           │
├─────────────────────────────┬───────────────────────────────┤
│      A类调优 (Ascending)      │      D类调优 (Descending)      │
│        提高通过率              │         降低逾期率             │
├─────────────────────────────┼───────────────────────────────┤
│ • 从拒绝客户中找好客户通过     │ • 从通过客户中找差客户拒绝      │
│ • 目标：逾期率不变，提高通过率  │ • 目标：通过率不变，降低逾期率   │
│ • 本质是"规则放松"            │ • 本质是"规则收紧"             │
│ • 拒绝客户无贷后表现（难点）   │ • 通过客户有贷后表现（易量化）   │
└─────────────────────────────┴───────────────────────────────┘
```

### 2.2 A类调优（提高通过率）

**核心目标**：在逾期率不变或可控的情况下，提高通过率，最终让业务收益最大化。

**目标公式**：`通过率↑ + 逾期率→ ≈ 业务收益↑`

**常见业务场景**：

| 场景 | 背景 | 调优逻辑 |
|-----|------|---------|
| **资金充足，有业绩压力** | 银行金融机构放款资金充足，有贷款规模指标 | 提高通过率完成放款规模，纯业务导向 |
| **策略过于保守** | 冷启动阶段风险审慎，后期发现风险极低 | 在风险可控前提下释放调整空间，扩大规模 |
| **通过率监控下降** | 规则/模型命中率周期性升高导致通过率下降 | 定位原因，进行相应策略调整 |

### 2.3 D类调优（降低逾期率）

**核心目标**：在通过率不变或影响可控的情况下，降低逾期率。

**目标公式**：`通过率→ + 逾期率↓ ≈ 业务收益↑`

**常见业务场景**：

| 场景 | 背景 | 调优逻辑 |
|-----|------|---------|
| **监控发现逾期上升** | 日常监控发现逾期率有明显上升趋势 | 定位原因，对症下药，进行策略调整 |
| **实际逾期超预期** | 上线后实际逾期率远超离线预测水平 | 回顾调整，将逾期率控制在预期范围内 |
| **放款资金减少** | 机构放款头寸不足 | 收紧策略，只放给资质较好的客户 |
| **市场环境下行** | 外部大环境不好，整体资产质量变差 | 控制风险敞口，适当收紧策略 |

## 三、策略调优标准流程

无论A类还是D类调优，均遵循以下5步流程：

```
┌──────────┐   ┌──────────┐   ┌──────────────┐   ┌──────────┐   ┌──────────┐
│ 步骤1     │ → │ 步骤2     │ → │ 步骤3         │ → │ 步骤4     │ → │ 步骤5     │
│ 分析需求   │   │ 确定方向   │   │ 量化分析制定   │   │ 执行测算   │   │ 评估验证   │
│ 确定调整   │   │ A类/D类   │   │ 调优方案       │   │ 调优效果   │   │ 是否达标   │
│ 环节/对象  │   │           │   │               │   │           │   │           │
└──────────┘   └──────────┘   └──────────────┘   └──────────┘   └─────┬────┘
     ↑                                                                 │
     └───────────────────── 未达标时循环步骤3-5 ────────────────────────┘
```

**步骤详解**：

| 步骤 | 工作内容 | 关键产出 |
|-----|---------|---------|
| **1. 分析需求** | 确定调整环节（贷前/贷中/贷后）、调整对象（规则/模型） | 调整范围明确 |
| **2. 确定方向** | 判断是A类调优（提高通过率）还是D类调优（降低逾期率） | 调优类型明确 |
| **3. 制定方案** | 通过科学量化分析方法论，制定具体调优方案 | 调优方案 |
| **4. 执行测算** | 执行调优方案，测算调整后的通过率/逾期率变化 | 效果测算表 |
| **5. 评估验证** | 通过评估指标验证效果是否达标 | 达标/未达标 |

> **核心理念**：大胆尝试，小心求证。整个过程需要反反复复对比，从优化方案中选择最优方案。

## 四、A类调优方法论

### 4.1 方法论总览

| 层面 | 方法 | 适用场景 | 核心逻辑 |
|-----|------|---------|---------|
| **宏观** | 客群下探 | 业务稳定，风险极低 | 下探更高风险客群，审批更严、额度更低、定价更高 |
| **微观** | 策略回捞 | 已有拒绝客户数据 | 从拒绝客户中筛选好客户回捞通过 |
| **微观** | 策略放松 | 规则有调整空间 | 对现有规则Cut Off做放松调整 |
| **微观** | 策略下线 | 策略效果差 | 评估后下线效果差的策略 |
| **微观** | 策略替换 | 有更好替代方案 | 新策略替换旧策略（Swap-in/Swap-out分析） |

### 4.2 宏观层面：客群下探

当现有客群风险基本可控且非常低时，可以继续下探更高风险的客群。

**下探客群的配套措施**：
- 审批策略更严格
- 授信额度更低
- 定价更高

### 4.3 微观层面：策略回捞

从策略流程前面节点命中拒绝的客户，通过筛选条件进行部分回捞，间接提高通过率，减少"误杀"好客户。

**核心逻辑**：选取**明显的好客户特征**，且这些特征与前面拒绝策略的数据维度**相关性越小越好**。

**回捞策略设计要点**：

| 要素 | 说明 |
|-----|------|
| 回捞变量来源 | 数据分析 + 业务经验挖掘 |
| 明显好客户特征 | 公务员/事业单位/500强企业员工、公积金缴存基数高（>5000/8000） |
| 强维度覆盖弱维度 | 因前面某些规则拒绝说明某维度风险高，需用更强维度抵消 |
| 规则组合形式 | 单规则回捞（力度大）vs 多维度交叉规则组合（更精准） |

**回捞策略决策流程设计**：

```
┌─────────────────────────────────────────────────────────────────┐
│                    贷前决策流程示例                               │
├───────┐  ┌───────┐  ┌───────┐  ┌─────────┐  ┌────────┐  ┌────┤
│政策准入│→ │黑名单 │→ │欺诈规则│→ │信用规则 │→ │拒绝回捞│→ │模型│
│       │  │       │  │       │  │         │  │  策略   │  │分层│
└───────┘  └───────┘  └───────┘  └─────────┘  └────────┘  └────┤
    ↓           ↓          ↓            ↓            ↑           │
 直接拒绝    直接拒绝     可回捞       可回捞      回捞通过      授信
                                                          ↓
                                                        出额/利率
```

> **关键注意事项**：
> - 政策准入、黑名单等原则性/底线规则**不可回捞**
> - 回捞节点通常放置在信用规则之后、模型分层之前
> - 回捞对象需根据业务判断（欺诈规则拒绝客户通常不回捞）

### 4.4 微观层面：策略放松

对现有规则的Cut Off做放松调整。例如：
- 原规则：近一个月贷款审批查询次数 ≥ 5 → 拒绝
- 放松后：近一个月贷款审批查询次数 ≥ 6 → 拒绝
- 效果：原值为5的客户现在被通过，整体通过率提高

### 4.5 微观层面：策略替换

用新策略替换现有旧策略，需进行**置换分析（Swap-in/Swap-out）**评估新旧策略效果。

**A类调优中策略替换的目标**：在逾期率不变的情况下，提升通过率。

## 五、D类调优方法论

### 5.1 方法论总览

| 层面 | 方法 | 适用场景 | 核心逻辑 |
|-----|------|---------|---------|
| **宏观** | 客群收紧 | 市场环境恶化 | 停掉高风险客群业务，仅保留低风险客群 |
| **微观** | 策略收紧 | 规则有收紧空间 | 将规则Cut Off做收紧调整 |
| **微观** | 策略替换 | 有更好替代方案 | 新策略替换旧策略（维持通过率，降低逾期率） |
| **微观** | 策略新增 | 现有策略无调整空间 | 新增策略提升命中率，降低逾期 |

### 5.2 宏观层面：客群收紧

以模型分层为主导的策略体系中（如A~F风险等级），当某风险分层风险过高甚至击穿安全线时：
- 停止高风险客群的业务（如原来通过A/B/C客群，现在停掉C，仅保留A/B）
- 或设置条件让高风险客群有条件通过（而非全部通过）

### 5.3 微观层面：策略新增

在现有策略不变的情况下，新增策略以提升整体命中率，达到降低逾期的目的。

**注意事项**：新增策略会带来通过率下降，需进行**通过率与逾期率的权衡**，综合考虑。

## 六、单变量规则的A类调优详解

### 6.1 核心概念：规则阈值放松

**示例**：
- 规则R0：最近一个月贷款审批查询次数
- 线上标准：R0 ≥ 5 时命中拒绝
- 阈值放松：将Cut Off从 ≥ 5 调整为 ≥ 6
- 效果：原R0=5的客户被通过，整体通过率提高（规则命中率降低）

### 6.2 A类调优的核心难点

**被拒绝的客户没有贷后表现**，即风险未知。

| 客户类型 | 流程结果 | 贷后表现 | 风险可知性 |
|---------|---------|---------|----------|
| 通过客户A | 通过 → 支用 → 还款/逾期 | 有（正常还款或逾期） | 可知 |
| 拒绝客户B | 被拒绝 → 流程结束 | 无（无法借款） | **未知** |

> 不能因客户B被拒绝就认定其一定是坏客户，也有可能是被误拒的好客户。

**通过样本分箱的局限性**：通过样本分箱后bad rate呈现的单调性，仅反映**通过客户**的风险分布。被拒绝客户（如变量值为8的客户）位于拒绝段，其bad rate需要**预测**。

### 6.3 拒绝段Bad Rate预测方法

#### 方法一：回归预测

**前置条件**：规则变量分箱后区间坏账率（Bad Rate）有明显的单调性。

**核心原理**：既然变量在通过样本上单调性良好，假设对拒绝客户放松后，大概率会延续该单调性。

**实现方式**：

| 工具 | 方法 | 说明 |
|-----|------|------|
| Python | `numpy.polyfit` 拟合线性方程系数和截距 | 分箱数为X，对应bad rate为Y，拟合线性回归模型 |
| Excel | 插入折线图 → 添加趋势线 | 可选线性/指数等类型，显示公式和R²值 |

**示例**：
- 拟合方程（线性）：`Y = 0.0233 * X - 0.006`
- 拟合方程（指数）：`Y = 0.02 * e^(0.188 * X)`
- 代入拒绝段分箱数（如5、6），求得预测的bad rate

#### 方法二：其他强变量

**适用场景**：当前规则的bad rate单调性不强，借助其他强变量预测。

**核心原理**：
1. **不同维度**：两个变量对同一样本预测的好坏值可能不同——一个规则拒绝的客户，在另一个变量上可能未被拒绝
2. **强变量要求**：该变量的分箱bad rate需有**非常强的单调性**（如模型分/融合模型分）

**操作步骤**：

```
步骤1：用强变量（如模型分）对规则通过样本打分 → 分箱 → 计算每箱bad rate
步骤2：用同一强变量对规则拒绝段样本打分 → 查看分布（理论上集中在低分段）
步骤3：假设强变量在相同分箱下，通过样本和拒绝样本的bad rate相同
步骤4：将步骤1的bad rate平移到拒绝样本的对应分箱
步骤5：每箱样本数 × 对应bad rate = 坏客户数 → 加总 → 计算整体bad rate
```

**示例计算**：
- 拒绝段5~6区间总样本：2000个
- 按模型分分箱后，各箱坏客户数加总：173个
- 预估bad rate = 173 ÷ 2000 = **8.65%**

> **经验型观点**：回归预测方法可能给出7%左右的估计，强变量方法给出8.65%。多种方法综合评估，结果更有说服力。

#### 方法三：实际测试

**方式1：随机测试（最直接、最准确）**

| 要素 | 要求 |
|-----|------|
| 分流比例 | ≤ 2%（不宜过高，否则坏账损失严重） |
| 样本量 | 需满足最小统计要求 |
| 豁免机制 | 测试样本只打分不生效，直接通过审批，不被后续策略拒绝 |
| 优点 | 通过实际贷后表现获取信息，最为准确 |
| 缺点 | 需观察周期；测试客户风险较高，会产生坏账损失 |

**方式2：历史AB测试**

- A组（对照组）：只打分不生效 → 可看到低于Cut Off客户的贷后表现
- B组（实验组）：打分且生效 → 部分客户被拒绝，看不到贷后表现
- 利用A组数据预估B组拒绝样本的bad rate

**方式3：历史灰度测试**

- 规则正式上线前的"陪跑"测试，只打分不生效
- 灰度测试距今需≥1个月表现期（观察首逾）；若观察DPD30+需更长
- 灰度期间样本量需满足统计要求

**AB测试 vs 灰度测试对比**：

| 维度 | AB测试 | 灰度测试 |
|-----|--------|---------|
| 时间 | 同时进行（对照组+实验组并行） | 不同时（灰度在正式之前） |
| 状态 | 部分生效、部分不生效 | 只打分不生效（全部不生效） |
| 用途 | 对比评估 | 预估规则效果 |

> **综合建议**：多种量化方法最好结合使用（如回归预测 + 强变量），综合多个维度分析结果更准确。

## 七、A类调优效果测算

### 7.1 测算目标

测算调优后对**通过率**和**逾期率**的影响，核心是比较**通过率上涨幅度**与**逾期率上涨幅度**。

### 7.2 测算步骤

**步骤1：样本选择**

| 要素 | 要求 |
|-----|------|
| 坏客户定义 | 如DPD30+ |
| 表现期 | 如3个月（Term=3） |
| 样本窗口 | 从当前向前推，选择近期样本 |
| 样本量 | 尽量多，尤其是坏客户数量需充足 |
| 样本组成 | 通过样本（有贷后表现）+ 拒绝样本（无贷后表现） |

**步骤2：通过样本分箱 + 预测拒绝段bad rate**

- 对通过样本按变量值分箱，统计每箱客户数、坏客户数、bad rate
- 利用回归预测/强变量/历史测试等方法预测拒绝段每箱的bad rate

**步骤3：构建完整测算表**

测算表包含以下核心指标：

| 指标类别 | 指标名称 | 含义 | 用途 |
|---------|---------|------|------|
| 基础统计 | 分箱区间 | 变量值区间 | 确定放松范围 |
| | 每箱数量 | 该区间客户总数 | 计算通过率 |
| | 区间bad rate | 该区间预估坏账率 | 计算逾期率 |
| | 好/坏客户数 | 基于bad rate推算 | 风险评估 |
| 通过率相关 | 累积数量之和 | 从好到坏累积加总 | 计算通过率 |
| | 累积占比 | 累积数量 ÷ 总样本数 | **直接反映通过率** |
| | 通过率上涨幅度 | (后通过率 - 前通过率) ÷ 前通过率 | 评估通过收益 |
| 逾期率相关 | 累积坏客户数 | 坏客户累积加总 | 计算整体逾期 |
| | 累积逾期率 | 累积坏客户 ÷ 累积总客户 | **反映整体逾期水平** |
| | 逾期率上涨幅度 | (后逾期率 - 前逾期率) ÷ 前逾期率 | 评估逾期成本 |
| 区分度 | Lift值 | 区间bad rate ÷ 整体bad rate | 评估区间风险程度 |

**步骤4：决策判断**

假设放松第N箱，比较两个涨幅：

```
┌──────────────────────────────────────────────────────────────┐
│  决策逻辑                                                      │
├──────────────────────────────────────────────────────────────┤
│  通过率上涨幅度 > 逾期率上涨幅度  →  值得放松，优化有效         │
│  通过率上涨幅度 ≈ 逾期率上涨幅度  →  无优化效果，不调整         │
│  通过率上涨幅度 < 逾期率上涨幅度  →  得不偿失，不调整           │
└──────────────────────────────────────────────────────────────┘
```

> **注意**：通过率和逾期率的绝对值量纲差异很大（如通过率涨7% vs 逾期率涨0.4%），不能直接比较绝对值，必须比较**涨幅比例**。

### 7.3 案例分析

以放开第5箱（变量值为5，≥5且<6）为例：

| 指标 | 放开前 | 放开后（+第5箱） | 变化 |
|-----|--------|-----------------|------|
| 通过率 | 43.55% | 50.32% | +15.56%（涨幅） |
| 逾期率 | 3.55% | 3.93% | +10.71%（涨幅） |

**判断**：通过率涨幅(15.56%) > 逾期率涨幅(10.71%)，差约5个百分点，说明这一箱可以放松。Lift值1.79不算特别高，整体风险可控。

再看第6箱：

| 指标 | 放开前 | 放开后（+第6箱） | 变化 |
|-----|--------|-----------------|------|
| 通过率 | 43.55% | 50.55% | +16.03%（涨幅） |
| 逾期率 | 3.55% | 4.02% | +13.23%（涨幅） |

**判断**：通过率涨幅(16.03%) 与 逾期率涨幅(13.23%) 接近，Lift值2.17，需谨慎处理，建议不放松。

第7箱及以后：通过率涨幅与逾期率涨幅几乎一致甚至倒挂，**坚决不放开**。

**最终建议**：本案例建议放开第5箱，上线后通过AB测试观察贷后表现，最终决定是否正式放开。

## 八、规则集的A类调优

### 8.1 核心指标定义

对于并行规则集（内部多条规则并行执行），需掌握三个核心命中率概念：

| 指标 | 定义 | 计算公式 | 关系 |
|-----|------|---------|------|
| **自然命中率** | 规则A命中的数量占样本总数的比例 | 规则A命中数 ÷ 样本总数 | 包含单一命中率 |
| **单一命中率** | 仅规则A命中、其他规则均未命中的数量占样本总数的比例 | 仅规则A命中数 ÷ 样本总数 | 被自然命中率包含 |
| **单一命中率纯度** | 单一命中率占自然命中率的比例 | 单一命中率 ÷ 自然命中率 | 反映独立命中占比 |

**自然命中率的构成**：
```
自然命中率 = 单一命中率 + 与其他规则的重复命中率
```

### 8.2 规则筛选逻辑（两步筛选法）

#### 第一步：单一命中率分析——筛选可调规则

**排除项**：
- 强规则（硬规则）：不轻易调整
- 正则性规则：固定逻辑
- 非连续性规则：如黑名单（只有0和1，无调整空间）

**筛选原则**：
1. **单一命中率大** → 有调整空间（如3.9%可调至2%或1%；0.1%几乎无空间）
2. **单一命中率纯度高** → 受其他规则影响小

> **核心逻辑**：调整单一规则的命中率 = 直接调整规则集整体的综合命中率（1:1对应关系），可精准控制。

#### 第二步：贷后逾期分析——二次筛选

在第一步筛选出的规则基础上，从逾期率角度进一步筛选：

| 有历史数据参考 | 无历史数据参考 |
|--------------|--------------|
| 历史随机测试数据 | 立即安排随机测试（需周期+损失） |
| 上线前AB测试/灰度测试数据 | **量化预估**（最常用） |

**量化预估方法**：
1. 观察规则变量在通过样本上的分箱bad rate单调性
2. 单调性强的规则：按趋势延续预测拒绝段bad rate
3. **优先选择单调性差的规则** → 拒绝段预估bad rate更低

**示例**：三个规则预估拒绝段bad rate对比

| 规则 | 单调性 | 预估拒绝段bad rate | 优先选择 |
|-----|--------|-------------------|---------|
| 规则0 | 较强 | 16% | 否 |
| 规则4 | 较强 | 19% | 否 |
| 规则7 | **较弱** | **12%** | **是** |

### 8.3 规则集性能计算与迭代

调整单一规则后，需重新计算整个规则集的综合性能：

```
单一规则调整 → 重新计算规则集综合命中率 → 评估效果
      ↑                                          │
      └────────── 未达标时返回重新筛选/调整 ─────┘
```

**迭代优化**：可列举多种备选方案组合，逐一执行并计算性能，选择最优方案：
- 仅调整规则1
- 同时调整规则1和规则2
- 调整规则1和规则2，但阈值调整方式不同

## 九、拒绝回捞策略的完整实施流程

### 9.1 离线分析步骤

| 步骤 | 内容 | 产出 |
|-----|------|------|
| **1. 确定回捞变量** | 数据分析 + 业务经验挖掘好客户特征 | 候选回捞变量池 |
| **2. 回溯回捞变量** | 将变量与历史样本数据对齐（含通过/拒绝样本的决策数据及通过样本的Y标签） | 对齐后的数据集 |
| **3. 筛选回捞变量** | 统计每个回捞变量下客群被策略规则拒绝的比例，评估回捞空间 | 可用回捞变量 |
| **4. 设计回捞策略** | 用代码执行回捞策略，测算通过率和逾期率 | 回捞策略方案 |
| **5. 评估回捞效果** | 评估通过率提升和预估逾期率；在近期样本上测算命中率验证稳定性 | 效果评估报告 |

### 9.2 回捞策略的逾期率评估

| 回捞变量类型 | 逾期率评估方法 |
|------------|--------------|
| 已在策略中使用的变量 | 直接利用历史贷后表现，分箱统计bad rate |
| 新的回捞变量 | 历史有测试 → 参考测试数据；无测试 → 预估 |

**回捞客群逾期率要求**：需明显低于整体大盘。如大盘bad rate为2%，回捞客群应控制在1.5%以内。

### 9.3 上线与监控

**上线方式**：AB测试（实验组20%执行回捞，对照组80%保持原策略）

| 阶段 | 监控重点 | 异常处理 |
|-----|---------|---------|
| 上线初期 | 回捞人群占比稳定性 | 回流量突然上升→风险预警信号，需排查 |
| 上线中期 | 回捞资产质量（FPD7/FPD15/FPD30） | 回捞风险≥大盘→策略失效，考虑下线调整 |
| 上线后期 | 贷后表现充分后全面评估 | 风险低且优势明显→扩大实验组比例直至全量 |

## 十、总结与关键要点

### 10.1 策略调优核心框架

```
策略调优
├── 两大方向
│   ├── A类调优（Ascending）：提高通过率
│   │   ├── 宏观：客群下探
│   │   └── 微观：回捞/放松/下线/替换
│   └── D类调优（Descending）：降低逾期率
│       ├── 宏观：客群收紧
│       └── 微观：收紧/替换/新增
├── 核心指标
│   ├── 通过率（A类调优关注）
│   └── 逾期率（D类调优关注）
└── 调优步骤
    ├── 分析需求 → 确定方向 → 制定方案 → 执行测算 → 评估验证
    └── 不达标时循环迭代
```

### 10.2 关键经验结论

| 序号 | 结论 | 类型 |
|-----|------|------|
| 1 | 风险往往是滞后的，需在环境变坏前提前收紧 | 经验型 |
| 2 | 没有最完美的策略，只有不同环境下最合适的策略 | 经验型 |
| 3 | A类调优中拒绝客户无贷后表现是核心难点 | 客观事实 |
| 4 | 拒绝段bad rate预测：多种量化方法结合使用更准确 | 方法建议 |
| 5 | 单调性差的规则优先放松（拒绝段预估bad rate更低） | 方法建议 |
| 6 | 通过率与逾期率的量纲不同，必须比较涨幅比例而非绝对值 | 数据验证结论 |
| 7 | 单一命中率调整量与规则集综合命中率变化量1:1对应 | 数据验证结论 |
| 8 | 回捞客群逾期率需明显低于大盘（如大盘2%，回捞<1.5%） | 经验型 |

### 10.3 常见误区

| 误区 | 正确做法 |
|-----|---------|
| 直接比较通过率和逾期率的绝对变化值 | 比较两者的**涨幅比例** |
| 仅用一种方法预测拒绝段bad rate | 多种方法**综合验证** |
| 优先选择单调性强的规则进行放松 | 优先选择**单调性差**的规则（拒绝段风险增长慢） |
| 回捞策略不加AB测试直接全量上线 | 先**小流量实验**，观察贷后表现后再扩大 |
| 忽略回捞客群的持续监控 | 上线后分阶段监控占比和风险指标 |
